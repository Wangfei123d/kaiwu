# 笔记画布

独立的笔记整理空间，不调用短剧生成引擎或模型。

## 打开与保存

重启开物加载新增插件后，在「窗口」中打开「笔记画布」。首次使用先配置笔记库，再新建画布。

画布文件会以独立的 `.canvas` 类型显示在笔记列表的「画布」目录中，并使用专属图标区分。点击列表中的画布文件会在「笔记画布」面板打开对应画布；新建画布后列表会自动刷新。

画布保存在 `<笔记库>/画布/<名称>.canvas`，导入图片保存在对应的 `<名称>.assets` 目录。可随笔记库一起备份；备份或移动时应一起保留画布和素材。

修改自动保存。遇到文件被外部修改、笔记库切换或保存失败时，不会强行覆盖；保留草稿，先解决原因，再重试或导出。不要把“保存失败”当作已保存。

未写入磁盘的草稿可在本次开物运行期间关闭/重开面板后恢复，但不是跨应用重启备份。退出或重启前，请先保存成功，或使用「导出草稿」保存 JSON（包含未应用的编辑正文）。

## 四类卡片

- 文本：画布自己的 Markdown 文本，不会自动创建一篇笔记。
- 文件引用：库内 Markdown、纯文本或图片。引用笔记的编辑会写回原文件；非 UTF-8 的只读笔记不会被强制转码保存。
- 链接：HTTP/HTTPS 地址，只在明确点击打开时进入系统浏览器，不自动加载远端页面。
- 分组：给一片卡片加边界和标题，移动时带上组内成员。

从笔记列表把库内笔记拖到画布可建立引用；外部图片通过导入保存成素材后成为卡片。支持 PNG/JPEG/WEBP/GIF/BMP，不接受 SVG 或网页文件。

## 操作

拖动卡片非编辑区域移动，角标调整大小。双击文本正文或文本/笔记卡片标题进入编辑。空白区域拖动框选，Shift 增选；从连接点连接卡片，给连线添加关系标签。右键复制/粘贴使用画布内部剪贴板，不改系统剪贴板。

Markdown 文本节点可直接在节点正文内编辑，格式实时呈现并随画布自动保存。`.md` 文件引用也可在节点内编辑，点击节点头部「保存」写回原文件；遇到外部修改冲突时草稿会保留并提示，可选择「重载原文」并确认后丢弃草稿、读取磁盘最新版。纯文本 `.txt` 保持纯文本显示，仍通过「编辑原笔记」打开纯文本编辑器。正文需要选择文字时按住 Alt。

普通滚轮平移，Shift + 滚轮横移，Ctrl/Meta + 滚轮围绕鼠标缩放。空格或中键拖动画布；节点内部正文独立滚动。缩放范围 25%–250%。

自适应平滑对离散滚轮使用较明显的缓动，对细粒度触控板快速响应；卡片拖动仍直接跟手。系统减少动态效果或开物关闭动效时，关闭缓动和滑行。

平滑动画中途被失焦、隐藏或切换打断时，当前中间视角可能不被保存；再次打开会恢复上一次保存的视角，节点内容和草稿不受影响。

## 格式与边界

使用 [JSON Canvas 1.0](https://jsoncanvas.org/spec/1.0/) 的文本、文件、链接、分组与连线结构，并保留开物视图位置。当前仅支持本页列出的文件类型；不宣称支持 Obsidian 的所有扩展字段。遇到不支持字段会明确拒绝，而不是静默删除数据。

单画布最多1000节点/5000连线/8MiB，临时文本最多200000字符，图片和引用笔记最大20MiB。文件只允许当前笔记库内的安全相对路径；不会把库外文件路径或不安全链接作为内容加载。

验证记录见 [实施计划](superpowers/plans/2026-10-09-note-canvas.md) 与 [界面验证报告](superpowers/plans/note-canvas-ui-report.md)。真实插件已在隔离浏览器和临时笔记库中验证；未重启当前开物进行实机验收。
