# 开物画布右键复制粘贴调整

- 日期：2026-10-04
- 方案：B（节点右键复制；画布空白处右键粘贴）
- 工作区：`E:\project\kaiwu`

## 目标与结果

关闭图片文件拖到画布时自动创建图片节点的行为，改为复制现有画布节点并在画布空白处粘贴副本。保留图片节点自己的导入按钮。

## 操作记录

1. 为画布增加节点剪贴板：右键复制当前节点或选中组，空白处右键粘贴到光标附近；组内保留相对布局。
2. 粘贴时为节点生成新 ID，深复制参数并保留宽高；不复制任何连线。只允许粘贴回来源短剧项目。
3. 增加 `Ctrl+C` / `Ctrl+V` 快捷键；输入框、文本框和可编辑区域里的原生复制粘贴不受影响。
4. 拦截图片文件和内部图片资源拖入画布，不创建节点、不触发浏览器打开图片；提示使用图片节点导入按钮。
5. 删除图片拖入预览与批量导入 IPC/辅助逻辑；保留 Word 拖放预览、Word 导入和单张图片导入 API。

## 技术要点与判断

- 节点复制数据仅保存在当前画布插件会话内，避免把节点参数写入系统剪贴板。
- 多节点复制以所选节点包围盒左上角为相对原点，粘贴时整体平移。
- 通过新建节点而非复用节点对象来生成副本，确保 ID 独立；不附带边集合以避免意外接线。
- 系统文件拖放由画布事件拦截；内部拖放总线在落点处拒绝图片载荷。Word 和视频路径未改为图片导入路径。
- 用户工作区已有大量暂存与未暂存内容；本次没有暂存、提交或覆盖其他文件。
