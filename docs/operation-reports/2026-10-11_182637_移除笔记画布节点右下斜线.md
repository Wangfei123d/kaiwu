# 移除笔记画布节点右下角斜线

## 操作背景
用户希望去掉笔记画布节点右下角的斜线装饰，同时保留节点尺寸调整功能。

## 操作过程
### 步骤一：定位装饰来源
- 做了什么：检查笔记画布样式中的 `.nc-resize` 规则。
- 结果：确认斜线由 `linear-gradient` 背景绘制，缩放热区与该背景彼此独立。

### 步骤二：新增回归检查并调整样式
- 做了什么：先新增测试，确认缩放把手仍保留缩放光标且不再绘制斜线；移除失败原因是覆盖规则优先级不足后，将背景覆盖规则设为 `.nc-pane .nc-resize`。
- 结果：17 项相关测试通过；JavaScript 语法检查通过。

### 步骤三：重启并查看实际界面
- 做了什么：确认画布状态为“已保存”后重启开物。
- 结果：启动日志显示笔记库可用，9 个插件加载、0 个失败。实际窗口中节点右下角斜线已消失，尺寸调整角仍在；画布状态仍为“已保存”。

## 涉及的知识点
- CSS 选择器优先级：两个规则优先级相同，先出现的覆盖会被后出现的规则重新设值。
- 样式与交互分离：去掉把手的绘制背景不会移除它的命中区域，也不会改动指针缩放逻辑。

## 分析过程
### 遇到的问题
第一次添加 `background:none` 后，测试通过但实际界面仍能看到斜线。

### 排查思路
对照截图与 CSS 规则顺序，发现新增覆盖在旧 `.nc-resize` 规则之前且特异性相同，因此浏览器最终仍采用旧渐变背景。

### 解决方案
给覆盖规则提高一个选择器层级，确保它优先于旧样式；保留现有 resize 规则、光标和事件逻辑，仅覆盖绘制背景。

## 注意事项
- 当前只移除视觉斜线，不影响节点拖拽缩放。
- 重启前确认画布已保存；没有编辑或删除用户节点。
