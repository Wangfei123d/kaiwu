A · 星尘聚像动感集中在画面中央，适合强调想象力和“汇聚成像”。
B · 横向流光最容易看见正在运行；扫光只覆盖预览画面，不改变状态文字。
C · 线稿生长视觉表达最强，但只适合短暂循环，可能让人误以为在展示真实中间结果。
D · 柔雾呼吸低干扰，适合较长耗时；状态点持续提供明确反馈。

预览使用示意插画表现动效位置；实际生成期间不会伪造中间图片或进度值。系统开启“减少动态效果”时动画会自动停用。
