# 独立笔记画布与自适应平滑操作记录

## 操作背景

用户预览并选择独立笔记画布和自适应平滑，随后确认两项一起落地。按用户选择直接修改 E:/project/kaiwu，保留已有改动，不新建隔离工作区、不提交或自行重启开物。

## 操作过程

### 一、确认范围与基线

- 笔记画布作为独立插件面板，不把笔记整理操作接入短剧生成引擎。
- 先确认笔记库、插件权限、工作区面板和拖拽总线的既有结构，建立分阶段实施计划。
- 基线全量1984项，1983通过、1跳过、0失败；没有把历史脏工作区当成可清理对象。

### 二、实现安全存储

- 新增 JSON Canvas 支持的文本、文件、链接、分组和连线结构验证。
- 保存到当前笔记库的画布目录；图片写入对应素材目录。新建不覆盖同名，更新采用旧版本比较和原子替换。
- 每次请求绑定笔记库身份，拒绝越界、符号链接逃逸、无效媒体与超限数据；编辑原笔记保持既有解码、换行与只读规则。
- 存储阶段先观察失败用例，再实现和独立审查，最终221项相关测试通过。

### 三、实现独立界面与导航

- 注册「笔记画布」面板，支持多个画布、Markdown文本、库内笔记/图片引用、链接、分组、连接和标签。
- 支持非编辑区拖动、调整大小、空白框选、Shift增选、右键局部复制粘贴、笔记列表拖入及图片导入。
- 自适应滚轮/触控板缓动，Ctrl/Meta滚轮以鼠标为中心缩放；节点拖动直接跟手。正文滚动独立，不误拖动整个画布。
- 自动保存采用串行快照；失败保留草稿，普通切换画布前必须成功保存。切库锁定旧图，可导出未应用的编辑正文。

### 四、隔离验证与独立复核

- 实际插件源码加载到独立无界面的 Edge，并连接真实画布存储接口及临时笔记库，不使用真实运行中的开物或用户笔记库。
- 用例检查创建/重载、Markdown、原笔记版本冲突、图片预览、拖动/框选/连线、分组/复制粘贴、缩放逐帧锚定、内滚动、草稿恢复、只读笔记、切库及关闭释放动画。
- 检查零外部网络请求、零页面/控制台错误、每个文件请求携带库身份；临时目录结束后清理。
- 初次最终复核发现连接状态生命周期问题；两条实际失败回归后完成统一取消和端点校验，四条回归通过，独立重审通过。

## 涉及的知识点

- 世界坐标与视图坐标：卡片记录自己的位置；视图平移、缩放只是改变看到它的位置，不需要把每个卡片改一遍。
- 版本比较：保存时先确认磁盘还是读取时的版本，避免覆盖别人或外部工具刚改过的内容。
- 原子保存：先写好完整的新文件，再一次替换，减少中途中断留下半个文件的风险。
- 库身份：路径相同不代表属于同一个库，所以文件操作还要核对当前库身份。
- 旧响应隔离：切换画布或关闭面板后，晚到的读取/保存结果不能修改新界面或新草稿。
- 自适应平滑：大步滚轮稍缓动，小步触控板更快响应；拖动不加延迟，并尊重系统减少动态效果的设置。

## 排查与分析过程

1. 引用笔记超过20MiB时曾先写入，再因计算版本失败报错。通过真实临时文件验证，改为先对最终编码字节做限额检查，再备份/写入。包含BOM、CRLF和多字节字符的测试证明原文件不被修改。
2. 旧面板的晚到保存回调曾删除或覆盖新面板的草稿。三个先失败后通过的回归用例覆盖旧成功、旧失败和已清洁新草稿；增加当前会话所有权检查，旧回调不再动新草稿，也不冒险自动改写磁盘版本。
3. 正文滚到边界后反向、正文选区复制、外部笔记更新后重新编辑、特殊节点ID等在实际浏览器用例中先暴露，再分别修复。
4. 删除已选的连接源或新建画布后，残留连接状态曾创建隐藏的无效边，导致后续保存失败。最终审查在真实临时库重现两条路径后，统一清理状态并在插入连线前核对端点。四条实际浏览器回归验证提交图、保存接口和磁盘文件，正常连接仍有效。

采用独立插件和受限文件接口，是为了沿用当前笔记库及面板机制，同时保持笔记整理与生成任务各自独立；复用既有安全Markdown渲染和笔记解码，避免引入第二套内容处理规则。测试先失败再通过，加上真实临时库界面验证，可以同时检查内部规则和实际点击行为。

## 注意事项

- 重启开物加载插件后，从「窗口」打开「笔记画布」，先配置笔记库。
- 备份画布时一起备份对应素材目录。保存失败并不等于已保存。
- 模块内草稿只在本次应用运行期间保留；退出或重启前需保存成功，或点「导出草稿」。
- 中途停止导航可能恢复上一次保存的视角，内容不丢失；没有为这一非阻塞问题扩大改动。
- 支持JSON Canvas的明确子集，不宣称兼容所有Obsidian扩展；未知字段明确拒绝，不静默删数据。
- 未做真实运行应用重启后的验收；未逐项独立断言操作系统图片拖入、笔记树拖拽、Space/中键平移等交互，完整边界见UI报告。
- 报告保存在项目内；「操作汇报」默认的D:/AI/AI操作汇报知识点不在本次写入授权范围内。
