# AI 生图结果显示于原框实施计划

**需求：** 用户要求生成结果显示在 D 动效所在的圆角框内。

**实现：** 按用户轮次关联 generate_image 和回复中的图片链接。由于 ACP 会把工具结束后的文字继续追加到工具之前创建的消息，不能只依赖消息位置。以调用 ID 保留预览元素，并从生图工具参数提取目标比例，在等待动画开始前设置预览框比例；结果图片铺满同一比例的框，未提供目标比例时按图片原始尺寸调整。链接可打开原图。正文保留源文本用于复制，通过渲染选项省略已经在框内展示的图片。
