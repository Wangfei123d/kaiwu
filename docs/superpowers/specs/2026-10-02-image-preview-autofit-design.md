# 图片生成节点预览框自适应设计

## 目标

修复图片生成节点被手动拉伸后，预览框仍固定高度、不能充分适配节点尺寸的问题。

## 已确认的设计

- 图片预览区域使用节点内容区的可用宽高，不再固定为 210 px。
- 主图保持原始宽高比并完整显示（`object-fit: contain`），不裁切、不拉伸。
- 多图时保留“大图 + 右侧缩略图”布局，缩略图栏高度跟随主预览区域；内容过多时在缩略图栏内部滚动。
- 用户显式设置节点宽高时，拖动缩放实时影响预览可用空间；未显式设置高度的节点沿用现有 210 px 预览高度作为默认内容尺寸，避免初次生成后预览塌缩。
- 不改生成模型、请求参数、图片文件格式或项目图数据结构。

## 实现范围

仅调整短剧画布图片预览的 CSS 布局及必要的视图测量逻辑，兼容已有的节点缩放、编辑态预览和图片缩略图切换。其他节点类型不受影响。

## 验收标准

1. 节点变窄或变宽时，主图在可用空间内完整显示且不溢出。
2. 节点变矮或变高时，预览区域跟随可用高度变化，不保留固定 210 px 的死区。
3. 横图、竖图均保持比例；主图不被裁切。
4. 多图缩略图仍可切换，缩略图多于可见高度时只在缩略图栏滚动。
5. 未手动设定节点高度时，预览保持可见且不塌陷。

## 不在范围内

- 改变图片模型或 APINebula 请求。
- 把一张拼图拆成多张图片。
- 自动修改已保存节点的宽高或迁移项目数据。
