# 笔记画布近黑主题设计

## 目标

让笔记画布的底色与开物程序全局主题统一为近黑色，同时保留足够的灰阶层次、文字对比度和浅蓝色交互强调。变更仅针对笔记画布，不调整全局主题，也不改动短剧画布。

## 设计

- 画布底色采用全局背景色 `--bg`（当前为 `#0e0e0e`），背景网格改为低对比度深灰点阵，保留空间定位但不抢内容焦点。
- 画布面板、节点和工具区使用由深到浅的中性炭灰层级，与全局面板观感一致；边框使用全局灰阶边框色。
- 标题、正文、辅助文字分别沿用全局主文字、弱化文字和次级文字颜色，维持清晰层级。
- 选中态、连接端口、焦点环和可交互强调继续使用全局浅蓝色 `--accent`；成功、警告、错误等状态色保持语义色，不被改成灰色。
- 输入框、悬浮菜单、工具栏、便签卡片及连接线一并纳入同一套近黑/灰阶配色，避免局部残留蓝灰主题。
- 保留现有节点拖动、编辑、缩放、连接、端口悬停显示、尺寸调整和布局，不改变交互与数据。

## 验收标准

1. 笔记画布背景呈近黑色，与开物全局背景一致，网格仍可辨认但低调。
2. 节点、工具栏、输入区和菜单有可分辨的深灰层次，文字对比清晰。
3. 选中、焦点及连接等强调色与程序浅蓝强调色一致；语义状态色仍正确。
4. 现有端口靠近显示、拖动、调整大小等交互规则不变。
5. 主题改动限于笔记画布，不影响其他页面和短剧画布。

## 不在本次范围

- 修改全局主题 token 或全程序其他区域的配色。
- 增加主题切换、用户自定义颜色或动画。
- 调整画布节点尺寸、布局、交互行为或存储格式。
