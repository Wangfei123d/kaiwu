# 笔记画布布局级缩放设计

## 目标

改善笔记画布在高倍率停稳后节点文字发糊的问题，同时保留已有的平滑缩放、平移、节点操作和连线对齐。

## 已确认方向

用户选择原型 B：布局级 `zoom`。不再把节点、文字和连线作为一个整体通过 `transform: scale()` 放大；改为外层 `.nc-world` 只负责平移，内层 `.nc-zoom` 对同一组节点、SVG 连线与框选层应用 CSS `zoom`。浏览器因此按缩放后的布局尺寸重新计算/绘制内容，而不是只缩放外层世界的视觉变换。

## 交互与数据

- 保持 `createNavigation` 的平滑插值、缩放边界（0.25–2.5）、指针锚点和视口保存方式。
- `.nc-world` 只接收 `translate(view.x, view.y)`；`.nc-zoom` 接收 `view.scale`。
- 节点、尺寸、端口、SVG 连线和框选层继续使用同一逻辑世界坐标，并共同处于缩放层。
- 屏幕坐标转换保持 `(screen - canvasOrigin - pan) / scale`；节点拖动、缩放、框选、素材投放仍在逻辑世界坐标中计算。
- 网格背景仍以倍率调整间距、以平移调整偏移，与内容保持对齐。
- 不迁移、不重写任何已保存画布数据。

## 性能与风险

布局级 `zoom` 每帧更新可能比单纯 transform 更耗布局/绘制成本。先沿用现有导航动画做小范围实现，并测试常规节点、连线与高倍率交互；若出现明显掉帧或坐标偏差，暂停并报告，不自行切换为另一种混合方案。

## 验收

- 高倍率停稳后，节点文字不再呈现被低分辨率整层放大的模糊感。
- 平滑缩放仍连续，指针锚点不漂移，倍率上下限不变。
- 节点拖动/调整尺寸、端口命中、SVG 连线与框选在缩放后保持正确。
- 应用现有画布数据不发生变更。
