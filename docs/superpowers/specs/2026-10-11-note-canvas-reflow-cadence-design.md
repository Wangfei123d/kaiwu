# 笔记画布节点重排频率设计

## 背景

笔记画布采用用户已确认的布局级缩放：外层负责平移，`.nc-zoom` 通过 CSS `zoom` 缩放节点和连线。当前导航动画每个 `requestAnimationFrame` 都发布一份视图状态；画布回调随即更新平移、CSS `zoom` 和网格样式。由于 CSS `zoom` 会触发布局，缩放时节点内容会随每一帧重新排布，产生用户感知到的抖动。

## 目标与范围

- 将笔记画布主视口的视图发布最小间隔设为 25ms（目标约 40 次/秒），合并间隔内多余的中间帧。
- 导航内部仍逐帧计算平移和缩放；每次实际发布时，平移、节点缩放、网格位置和网格间距使用同一份视图快照。
- 缩放/平移动画结束时立即发布精确最终状态，不留下视觉落后。
- `set()`、减少动态效果模式下的立即更新、用户显式停止动画时同步当前状态；销毁实例时不额外刷新。
- 只对笔记画布主视口启用 25ms 间隔。节点正文的内部滚动导航、Markdown 编辑器重排、自动保存间隔、连线和画布数据格式均不改变。

## 备选方案

1. **25ms 最小发布间隔（选择）**：保留平滑的内部插值，减少应用到 DOM 的视图帧；直接回应“稍微延长节点内容重排间隔”，并避免改变已选的布局级缩放架构。
2. 33ms 间隔：进一步降低布局次数，但可见缩放/平移约为 30 次/秒，较容易呈现阶梯感。
3. 保持每帧重排，只延长缩放时间常数：动作更慢，但重排次数不减少，未直接解决节点内容频繁重排。

## 交互与状态

- `createNavigation` 增加可选的帧发布最小间隔，默认 0，确保其他现有调用不变。
- 画布主导航配置 25ms；每帧仍更新内部 `view`，到发布时限后只发送最新快照，跳过过期中间快照。
- 每帧快照仍沿用原有指针锚点和同一逻辑世界坐标。动画收敛、显式停止和直接设置视图时保证最后一份可见样式与导航状态一致。
- 不迁移或重写任何画布数据，不更改视口坐标、缩放倍率范围、平滑参数或节点尺寸。

## 测试与验收

- 使用可控时钟验证：启用 25ms 间隔时，内部视图仍可逐帧变化，但发布回调按最小间隔合并中间帧。
- 对每份发布快照验证指针锚点不漂移；在 25ms 阈值边界下，结束时仍发布精确最终视图。
- 验证 `set()`、减少动态效果模式、`stop()`、`dispose()` 的刷新/取消行为，并确认未配置间隔时原行为不变。
- 在笔记画布启用 25ms；正文滚动导航仍用默认逐帧更新。
- 聚焦运行导航与笔记画布相关测试，并在应用中观察滚轮缩放：抖动减轻、最终节点清晰、网格对齐、拖动/缩放坐标未回归。

## 风险与缓解

- 画布可见更新节奏会从显示器的每一帧降至至少相隔 25ms；低刷新率或高刷新率设备上实际节奏会受 `requestAnimationFrame` 帧率影响。用终态强制发布避免停止时残留旧尺寸，并通过运行验证确认节奏没有明显阶梯感。
- 快速交互时内部导航状态可能领先最后一次可见发布最多约 25ms；发布时将整份视图快照一起应用，避免节点、平移和网格来自不同帧。

## 明确不做

- 不切换回整层 `transform: scale()` 或增加混合缩放层。
- 不调整 Markdown 输入重渲染、自动保存或节点正文滚动的节奏。
- 不改动用户保存的画布、插件布局或普通笔记编辑器。
