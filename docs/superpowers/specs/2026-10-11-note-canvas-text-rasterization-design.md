# 笔记画布放大文字清晰度设计

## 目标

在笔记画布较大倍率缩放后，节点内文字仍清晰可读，同时保留现有平滑缩放、节点布局和画布交互。

## 现状与根因假设

运行画面中节点正文随画布放大后发糊，但工具栏文字仍清晰。`plugins/note-canvas/canvas-view.js` 每帧对包含节点和连线的 `.nc-world` 应用 `translate(...) scale(...)`；`plugins/note-canvas/style.css` 又为该整层长期设置 `will-change: transform`。该固定合成提示可能使 Chromium 在高倍率下复用低倍率栅格缓存。相邻短剧画布也缩放 `.drama-world`，但没有相同的长期合成提示。

## 方案与边界

- 移除 `.nc-world` 上长期固定的 `will-change: transform`，由浏览器按当前缩放重新栅格化画布文字。
- 保留现有 CSS transform、缩放边界、平滑导航动画、坐标换算、节点与 SVG 连线结构；不更改画布数据。
- 不改用布局缩放或逐节点反向缩放，避免影响命中测试、布局和连线坐标。
- 验证放大停稳后的文字清晰度及导航/节点交互回归；若文字仍发糊，再重新调查渲染层方案，不叠加猜测式补丁。

## 风险与权衡

移除长期合成提示可能增加缩放过程中的重绘，但预期只影响笔记画布这一层。验收重点是高倍率停稳后的文字清晰度，以及平滑缩放和画布操作保持正常。
