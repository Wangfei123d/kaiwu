# 笔记画布两秒布局重排设计

## 背景

笔记画布用外层平移与 `.nc-zoom` 的 CSS `zoom` 放大节点和连线。CSS `zoom` 会触发布局，当前将整份视图回调限制为 25ms 后，平移与缩放也一起降频。用户希望将节点内容的精确布局重排间隔放宽至 2 秒，同时保持缩放连续。

## 目标与范围

- 笔记画布主视口导航继续逐 `requestAnimationFrame` 更新，平移和缩放的视觉动作不按 2 秒冻结。
- 交互期间，节点内容的 CSS `zoom` 精确重排至少间隔 2000ms；到期时提交最新的缩放比例，不补算过期中间状态。
- 仅当导航比例与最近一次精确布局比例不同时才安排重排；纯平移或缩放回到已提交比例时不做无效布局。
- 两次精确重排之间，以临时视觉缩放补偿，使画面有效缩放仍等于导航当前比例；文字可能短暂略软，精确布局提交后恢复清晰。
- 当交互停在两次重排之间，保留临时缩放；到下一次允许提交时立即同步最终比例，等待最长不超过剩余间隔。
- 打开/切换画布或恢复保存的视口时立即同步基础缩放，避免首次显示错误或等待；之后的交互重排遵循 2000ms 间隔。
- 减少动态效果模式保持现有即时视图更新，并即时同步精确布局，不引入临时软化或 2 秒等待。
- 不改变画布数据、缩放边界、指针锚定、平移/缩放插值、连线、节点尺寸、Markdown 编辑、自动保存或节点正文滚动。

## 设计

### 双层缩放

- 保留 `.nc-zoom` 的 CSS `zoom`，作为最近一次精确布局提交的比例 `layoutScale`。
- 在其内部增加 `.nc-motion` 容器，包住连接 SVG 与节点层，设置左上角为变换原点。
- 每个导航动画帧继续更新外层世界平移、网格位置/间距，并给 `.nc-motion` 设置临时比例 `view.scale / layoutScale`。
- 组合后的有效比例为 `layoutScale × (view.scale / layoutScale) = view.scale`，所以节点、连线与网格仍跟随当前视图；指针世界坐标仍使用导航当前视图计算。
- 每次精确布局提交时，将 `.nc-zoom` 的 CSS `zoom` 更新为最新比例，同时将 `.nc-motion` 临时比例归一到 1；两者组合前后保持同一有效比例，避免视觉跳变。

### 重排节奏

- 新建独立的布局缩放节奏控制器，不再限制主导航的帧回调。
- 控制器接收每帧的当前比例，立即更新临时比例；只有距上次精确提交已满 2000ms 时才更新 CSS `zoom`。
- 若交互在间隔内结束，控制器设置一次延迟任务，在下一允许时刻将最新比例提交为 CSS `zoom`，并清理临时缩放。
- 如果当前比例回到已提交比例，则清除不再需要的延迟任务；减少动态效果模式直接调用同步路径。
- 打开/切换画布时以保存的视口比例立即同步基础层；该同步是初始化/恢复，不属于连续导航过程。
- 销毁画布时清理待执行任务，避免已卸载视图后更新 DOM。
- 节点正文滚动继续使用独立导航，不增加 2 秒延迟。

## 测试与验收

- 用可控时钟验证临时比例每帧跟随当前比例，而精确 CSS `zoom` 提交任意两次至少相隔 2000ms。
- 验证连续更新跨过 2000ms 后只提交最新比例，不重放中间比例。
- 验证间隔内停止后会在最近允许时刻提交最终比例；销毁后不再执行待处理更新。
- 验证纯平移/比例复原不产生多余布局，减少动态效果模式会立即精确同步。
- 验证组合比例恒等于导航视图比例，平移、背景网格与指针锚点坐标仍保持一致。
- 验证画布切换/视口恢复立即同步基础缩放，节点正文滚动、Markdown 编辑与自动保存不变。
- 运行导航、渲染和笔记画布集成相关测试，并在开物中观察持续缩放、停止后的清晰度恢复及点击/连线/拖动坐标。

## 风险与缓解

- 临时 CSS transform 会使文本在两次精确重排之间略微软化，最长约 2 秒；采用左上角变换原点，并用组合比例保持几何位置与尺寸一致。
- CSS `zoom` 与内部 transform 的组合可能影响实际点击区域；通过浏览器/应用交互验证节点、连接端口和拖动命中范围与画面一致。
- 若临时变换在 Electron 的 CSS `zoom` 下出现比例差异，允许将 `.nc-motion` 拆为更明确的包装层，但不得让平移、网格或数据坐标依赖旧的 `layoutScale`。

## 明确不做

- 不把整个画布的平移/缩放发布节奏改为 2 秒。
- 不改变动画缓动参数或缩放边界。
- 不对笔记编辑文本、节点正文滚动或自动保存增加延迟。
- 不迁移或重写任何用户画布数据。
