# 笔记画布空白处双击新建文本节点

## 背景

笔记画布目前没有为画布空白区域注册双击动作。用户只能通过工具栏新建文本节点，再手动定位并进入编辑。节点正文编辑采用实时 Markdown 编辑器；普通节点交互是先单击选择，再次单击进入编辑。

## 目标

在可编辑画布中双击空白位置时，直接创建一个文本节点并进入节点内编辑，让用户可以立即输入内容。

## 交互范围

- 只响应画布空白处的双击；双击已有节点、节点控制点或连线不创建新节点，现有行为保持不变。
- 只在画布可编辑且当前画布已加载时创建节点；只读或未加载状态不产生变更。
- 使用双击屏幕坐标经现有 `worldPoint` 换算后的画布坐标，将新建节点中心放在双击位置，避免缩放或平移时坐标偏移。
- 创建空白文本节点，选中该节点并立即启用节点内 Markdown 编辑器，焦点落在正文中以便直接输入。新建内容不写入工具栏当前使用的教学提示文本。
- 新建沿用现有文本节点尺寸、保存/自动保存和选择状态逻辑；节点仍通过现有画布会话持久化。新建流程可显式指定空文本，同时保留工具栏创建节点的默认提示语。

## 不在范围内

- 不改变节点单击选中、再次点击编辑的既有规则。
- 不改变双击连线编辑标签、节点连接、画布缩放/平移、节点拖动和节点创建工具栏行为。
- 不新增快捷键、设置项或视觉动画。

## 实施与验证要点

- 在画布层增加有目标过滤的双击处理；避免双击节点正文、端口、尺寸控制器或边时误建节点。
- 新建流程复用现有文本节点创建与渲染逻辑；创建器需区分“未提供文本”（沿用工具栏提示语）与“显式空文本”（双击创建），渲染后再启用对应正文编辑器。
- 验证：双击空白处生成且只生成一个空白文本节点并自动选中、进入编辑；不同缩放/平移视图下节点中心对准双击位置；节点、连线和只读状态下不误创建；现有节点选择/编辑交互无回归。
