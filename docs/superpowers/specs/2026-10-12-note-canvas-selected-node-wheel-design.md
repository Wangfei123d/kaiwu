# 笔记画布：仅选中节点响应滚轮

## 目标

让笔记画布节点正文只有在所属节点被选中后才响应鼠标滚轮，避免未选中的节点意外滚动。

## 交互规则

- 已选中的节点：普通滚轮滚动该节点正文；Ctrl/⌘ + 滚轮沿用现有画布缩放行为。
- 未选中的节点正文：滚轮不滚动正文，也不触发画布平移或缩放。
- 指针位于节点正文以外：画布现有平移和缩放行为保持不变。
- 同一选择集合内的每个节点均视为已选中；普通单选仍按现有选中逻辑工作。

## 实现边界

在节点正文滚轮处理器中关联所属节点 ID，并在处理事件前检查该 ID 是否存在于当前选择集合。未选中时取消浏览器默认滚动并停止传播，但不启动节点滚动动画，也不触发画布导航；这样可避免浏览器原生滚动穿透。选中时继续使用现有平滑正文滚动；Ctrl/⌘ 组合键继续委托当前画布缩放处理。

不改变节点选择手势、滚动条样式、画布外滚轮导航、节点编辑、保存或数据格式。

## 验收

1. 未选中的普通文本节点正文滚轮不会移动正文。
2. 选中文本节点后，其 Markdown 正文滚轮可平滑滚动。
3. 选中可滚动的 Markdown 文件节点后，正文滚轮仍可平滑滚动。
4. 对未选中节点正文滚轮不会平移/缩放画布；节点外画布导航不变。
5. 选中节点上 Ctrl/⌘ + 滚轮仍按现有规则缩放画布。
6. 相关自动化测试通过，并在改动后重启开物确认启动正常。
