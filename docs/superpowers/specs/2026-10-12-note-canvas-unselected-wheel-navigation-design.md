# 笔记画布：未选中节点上的滚轮用于画布导航

## 背景与目标

当前节点正文滚轮监听会先调用 `preventDefault()` 和 `stopPropagation()`，之后才判断所属节点是否选中；画布监听又忽略所有 `.nc-node-body` 内的滚轮事件。因此，指针位于未选中节点正文上时，滚轮既不会滚动正文，也不会移动画布。本规格更新并取代 `2026-10-12-note-canvas-selected-node-wheel-design.md` 中“未选中节点上的滚轮无效”的规则。

## 交互规则

- 未选中节点正文上滚动滚轮：正文不滚动，事件交给笔记画布，按现有规则平移画布。
- 已选中节点正文上滚动滚轮：继续由该节点正文的现有平滑滚动逻辑处理。
- 已选中节点正文上的 Ctrl/⌘ + 滚轮：继续触发画布缩放。
- 节点正文以外的画布平移/缩放行为不变。
- 如果多个节点处于选择集合中，集合中的节点均视为已选中，正文滚轮仍由各自正文处理。

## 设计与范围

只调整 `plugins/note-canvas/canvas-view.js` 内节点正文与画布之间的滚轮事件路由：未选中时不取消默认事件、不停止冒泡，让现有画布监听接手导航；已选中时仍由节点监听取消事件并滚动正文。保留现有导航控制器、滚动动画、修饰键行为和 CSS。无需更改数据结构、选择手势或节点编辑逻辑。

## 验收

1. 未选中普通文本节点上滚轮会平移画布，正文位置不变。
2. 选中文本节点上普通滚轮仍平滑滚动正文，不平移画布。
3. 选中可滚动的 Markdown 文件节点时行为一致。
4. Ctrl/⌘ + 滚轮缩放和画布空白处导航保持原行为。
5. 相关自动化测试通过；改动完成后重启开物并确认启动正常。
