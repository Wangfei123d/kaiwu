# 开物工具移入“窗口”菜单设计规格

日期：2026-10-14  
状态：待用户审阅  
范围：导航入口与窗口菜单，不改变工具本身的功能

## 背景

当前应用顶部有“工具”视图，视图中通过侧栏展示工具清单。用户希望移除顶部工具入口与工具侧栏，并将工具集中到原生菜单“窗口 → 工具”下，按需打开。

当前生产工具包括：B站解析下载、抖音解析、音乐试听、调色板 & 渐变、字幕格式互转、单文件示例。它们均已注册为工作台面板（`workspacePane: true`）。笔记画布、短剧工作台、AI 会话等属于工作台功能面板，不属于工具子菜单。

## 目标交互

1. 移除顶部“工具”主视图入口及其侧栏、错误列表和工具内容区；笔记、设置等其他视图保持原样。
2. 在原生“窗口”菜单中增加“工具”子菜单，按工具注册顺序列出已注册的工具；当前六项使用注册表标题与顺序，不硬编码名称。
3. 工具项按需打开：未打开时创建对应独立工作台面板；已打开但当前隐藏时切换并聚焦到该面板；当前已显示时标记为打开状态并禁用点击。沿用现有窗口面板的三态语义。
4. 工具面板只出现在“窗口 → 工具”子菜单，不再重复出现在“窗口”下的普通面板列表。其他非工具工作台面板仍按当前顺序和规则列在普通面板区。
5. “窗口”菜单中“工具”子菜单与普通面板区之间保留分隔；若当前没有已注册的工具，不显示空子菜单或多余分隔。
6. 点击菜单项目时，若工具在当前会话中已停用、未登记或其面板规格缺失，安全忽略此次过期菜单事件，不创建未知面板，也不影响工作台。

## 菜单状态规则

| 工具面板状态 | 菜单显示 | 点击行为 |
| --- | --- | --- |
| 未打开 | 未勾选，可用 | 新建该工具面板并聚焦 |
| 已打开但在非活动标签中 | 已勾选，可用 | 切换到该工具面板 |
| 正在显示 | 已勾选，禁用 | 无操作 |

菜单条目使用原生 checkbox 状态，保持现有跨平台外观。普通面板区继续使用既有三态规则。

## 数据与结构

- 菜单内容以运行时工具注册表为准，保留各工具的 `pluginId`、工具 `id`、标题及排序信息；通过已有的 `tool:${pluginId}:${id}` 视图 ID 与工作台面板关联。仅列出 `workspacePane: true` 且对应面板规格已注册的工具。
- 渲染层状态报告采用明确分组 `{ views, tools }`：`views` 是普通工作台面板表，排除所有工具视图 ID；`tools` 是已注册工具的面板状态表。主进程分别校验两组纯数据，并传入菜单模板。布局或注册表变化时，两组数据一起参与去重比较和重报。
- 原生菜单模板继续保持纯函数：接收普通面板表与工具表，产出“窗口”菜单。工具菜单项使用工具面板视图 ID，并复用已有 `menu:add-view` 事件及 `knownIds` 校验，确保已打开工具可聚焦、未打开时可创建。
- 删除 `paneTools` 与 `.view-tab` 工具入口的引用后，不再初始化通用工具侧栏或工具内容渲染器。插件注册、面板挂载、能力和插件错误记录机制不随导航入口删除。
- 菜单表仅接收渲染层必要的纯数据；主进程继续过滤字段，不将插件对象或可执行内容传入菜单模板。

## 范围外

- 不修改六个工具的功能、布局、服务生命周期或插件权限。
- 不改变笔记、设置、短剧工作台、笔记画布、AI 会话等视图入口。
- 不改变窗口菜单普通面板的排序、三态行为、关闭/最小化等窗口命令。
- 不新建独立操作系统窗口；“独立面板”指工作台内的独立可平铺面板。
- 不删除工具注册表、插件清单、侧栏模块本身；仅移除主应用当前对工具视图与侧栏的使用。

## 验收标准

1. 顶部不再出现“工具”视图入口，应用主视图中不再呈现工具侧栏。
2. “窗口 → 工具”按注册顺序出现六个当前工具，标题来自注册表。
3. 从菜单首次选择一个工具会新建并聚焦唯一面板；之后再次选择隐藏的该面板会聚焦已有面板，不产生副本。
4. 当前显示的工具项已勾选且不可点击；已打开但隐藏的工具项已勾选且可点击。
5. 普通“窗口”面板列表不含工具视图，其他工作台面板项目维持既有行为。
6. 插件注册顺序/可用工具变化能反映到菜单；空工具列表不留下空子菜单或分隔线。
7. 自动化测试覆盖菜单结构、工具和普通面板去重、菜单状态三态、过期工具 ID 防护，以及普通面板菜单的既有回归。

## 影响范围（预计）

- `app/index.html` 与视图切换相关的 `app/main.js`：移除工具主视图/侧栏装配。
- `electron/app-menu.js`、`electron/main.js`、`electron/preload.cjs`：传递 `{ views, tools }` 分组菜单数据、构建工具子菜单；保留 IPC 数据校验和现有面板打开事件。
- 菜单模板与渲染层菜单表测试，以及必要的插件/集成验收测试。

## 未决事项

无。交互范围与菜单分组已由用户确认。
