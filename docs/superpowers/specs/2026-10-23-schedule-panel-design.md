# 日程面板设计

## 目标

在开物中新增一个“日程”工具，采用已选定的方案 A：左侧月历选日期，右侧显示当天的时间安排和待办事项。

## 实现方式

- 将功能做成独立插件，使用现有工具注册、面板挂载和插件样式隔离机制。
- 月历显示周一至周日、当天标记、选中状态和有事项日期标记；支持切换月份与回到今天。
- 当日区域按时间展示日程，并在下方显示待办；待办可以勾选完成。
- 提供新增、编辑和删除操作。日程有开始/结束时间，待办可选日期和备注。
- 日程支持单次或循环。循环时先选按周或按月，再在周日历/月日历中点选一个或多个日期；周循环保存星期，月循环保存月日。
- 循环日程在开始日期之后的匹配日期显示，并在对应日期的月历标记和当天列表中出现。月内不存在的日期自动跳过。
- 通过插件自己的 settings 命名空间保存数据，只存本地，不连接外部日历、不导入示例数据。
- 窄面板下将月历和当日列表纵向排列。

## 不在本次范围

提醒通知、跨设备同步、外部日历导入导出和多人共享。

## 验收标准

1. “日程”可从开物工具列表打开，布局以月历加当日日程为主。
2. 用户可切换日期和月份，新增/编辑/删除日程或待办，并勾选待办完成。
3. 重新打开面板后仍能读取之前保存的条目。
4. 日历会标记有安排的日期，界面适配窄面板。
5. 循环规则会持久化；切换到匹配日期时显示该日程，单次日程仍只显示在所选日期。
